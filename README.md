# roadmap.sh_intermediate_projects

- [Caching Proxy](https://github.com/p-e-g-a-h/roadmap.sh_intermediate_projects/tree/main/Caching%20Proxy): A CLI tool that speeds up requests by caching responses in Redis and adding X-Cache headers to show if data is fresh or cached.
- [Markdown Note-taking App](https://github.com/p-e-g-a-h/roadmap.sh_intermediate_projects/tree/main/Markdown%20Note-taking%20App): A REST API to check grammar, save Markdown notes, and render them instantly as HTML.
  - Live Demo: https://markdown-note-taking-app-8zlh.onrender.com/
- [URL Shortening Service](https://github.com/p-e-g-a-h/roadmap.sh_intermediate_projects/tree/main/URL%20Shortening%20Service): A minimalist Node.js API that converts long URLs into trackable, alphanumeric short links using SQLite.
  - Live Demo: https://url-shortening-service-sue4.onrender.com/
- [Broadcast Server](https://github.com/p-e-g-a-h/roadmap.sh_intermediate_projects/tree/main/Broadcast%20Server): A real-time CLI chat tool that uses Socket.io and node:readline to broadcast messages instantly to all connected users.
